# Heart Disease Prediction using Machine Learning

## a. Problem Statement
The objective of this project is to predict the presence of heart disease in patients
using clinical and demographic health indicators.

## b. Dataset Description
- Dataset: UCI Heart Disease Dataset (Kaggle)
- Instances: ~1025
- Features: 13
- Target: Binary (0 = No Disease, 1 = Disease)

## c. Models Used
- Logistic Regression
- Decision Tree
- KNN
- Naive Bayes
- Random Forest
- XGBoost

## d. Streamlit App
The Streamlit app allows users to select a model and view evaluation metrics
along with the confusion matrix.
